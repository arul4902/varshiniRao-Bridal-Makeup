## Brand Overview

- **Philosophy**: *"Makeup that still feels like you."* (Skin-first bridal artistry preserving natural texture & authentic glow).
- **Signature Hook**: *"Not sure what makeup suits YOU? Get a 15-min personalised consult."*
- **Aesthetic**: Editorial bridal magazine + luxury beauty studio. Warm ivory (`#FBF8F4`), soft beige (`#EFE7DF`), muted rose (`#CDA9A0`), deep espresso (`#2A211E`), and subtle champagne gold (`#B79A6B`).

---

## Key Features

1. **Editorial Hero Section**: High-impact Muhurtham bride imagery, brand manifesto, and direct conversion hooks.
2. **Meet Varshini**: Authentic portrait from Mysore studio, artist philosophy, and core pillars.
3. **15-Minute Personalised Consultation**: Structured 3-step consultation framework with direct WhatsApp scheduling.
4. **Bridal Services Suite**: Muhurtham, Evening Reception, Engagement/Roka, Saree Draping & Box Pleating, and 1-on-1 Masterclasses.
5. **Interactive Look Finder**: 3-step visual preference selector that auto-populates the booking form and WhatsApp chat.
6. **Real Brides & Video Reels Lightbox**: Category filter tabs and modal lightbox supporting authentic photos and Instagram video reels (`.mp4`).
7. **The Transformation (Draggable Split Slider)**: Interactive touch & pointer comparison slider showing skin-first artistry.
8. **Client Love & Student Testimonials**: Real verified bride reviews and student mentor feedback from Instagram story highlights.
9. **Beauty Notes by Varshini**: Educational beauty advice (including foundation recommendations for oily skin and Muhurtham longevity).
10. **Smart Date Enquiry Engine**: Real-time structured WhatsApp inquiry generator (+91 91876 54470).
11. **Responsive Multi-Device Layout**: Fully tuned across Mobile (320px–768px), Tablets (769px–1024px), Laptops (1025px–1366px), and Desktops (1440px+).

---

## Tech Stack & Architecture

- **Core**: Vanilla HTML5 + Vanilla ES6+ JavaScript (Zero framework overhead, `< 11 kB` gzipped total bundle).
- **Build Tool**: Vite 5
- **Styling**: Modular Vanilla CSS Design System with CSS variables and fluid typography (`clamp()`).
- **SEO & Social**: Schema.org `BeautySalon` JSON-LD, OpenGraph tags, semantic landmarks.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Runs locally at `http://localhost:5173/`.

### Production Build
```bash
npm run build
```
Generates production-ready, minified bundle in `/dist`.

### Preview Production Build
```bash
npm run preview
```
